### Overview
- React is a front-end library for building UIs that uses a virtual DOM instead of a real DOM
- JSX allows you to put HTML tags in the DOM quickly and easily
- Typescript is a strongly-typed version of JavaScript
- Transpiling means compiling from one high-level language to another high-level language
- Maintaining State means keeping track of a user’s data and progress as they go through your website.
- Hooks are React components to make your life easier.

### What is React?
- React is a front-end JavaScript library that lets you build user interfaces (UIs) using components
- React is free and open source
- React library was created by Facebook in 2011 and it still maintained by Meta.

#### How Does React Work?
- React created a virtual DOM in the web browser's memory
	 *Brother what?*
- This Virtual DOM is easier to work with than the actual DOM, which tends to be complicated
- Node.js isn't needed for React but we gonna use both.
- The term **MERN Stack Development** means MongoDB, Express, React, Node.js

### JSX
- JSX stands for JavaScript XML
- It allows you to write HTML elements in JavaScript and then put them in the DOM without `createElement()`, `appendChild()`, `nextElementSibling()`, etc.
	 *Thank fuck.*
- Example: `const myElement = <h1>This is Cool</h1>`

### What is Transpiling?
- Compiling: Converting high-level code (Java, C#, etc..) to low-level machine language.
- Transpiling: Compiling high-level code to another high-level language (JSX -> JavaScript)
- Babel is a popular transpilier
- You can transpile at the command line each time you modify your code

- Or you can add a build script to automate the transpiling every time you modify your code

### What is VITE?
- VITE (pronounced *veet*) is a modern build tool created by the created of Vue.js
- It helps make web development faster and smoother
	- Uses native browser modules your app starts instantly
	- Hot reload without losing state
	- Simpler config - less setup and fewer dependencies
	- Supports JSX, TypeScript, CSS, etc.

### Maintaining State
- The Internet is stateless by default, which means every time the user clicks a link or button, all data is lost.
- We need to keep track of user data. This is called **Maintaining State**.
- React has some cool features called **Hooks** that make this easy.

#### Hooks
- Hooks are prebuilt React components that allow you access to state and other react features
- With Hooks, you don't need to create an instance of a class.
