### Template Engines
- In client-side JavaScript, template engines helps us create an HTML template with minimal code. 
- It can also inject data into HTML templates at client side and produce the final HTML. 
- We can use a template engine (JavaScript Library) to use JavaScript to create dynamic HTML using a pre-defined HTML structure mixed with special syntax.
- Saves doing DOM manipulation with JavaScript to create dynamic content, speeds up and simplifies development.
- Someone with HTML skills only can create HTML templates without having to know JavaScript. A JavaScript developer can work in parallel with a UI/UX developer with only HTML skills

#### Templating Engines - Server-Side
Templating engines are also available for Node.js and specifically the Express Framework. Work is very similar to client-side templating.
- Handlebars
	- `hbs`
	- `express-hbs`
	- `express-handlebars`
- EJS (Embedded JavaScript Template Engine)
- Pug
- Haml.js

Handlebars seems to be the one we have kind of used, it can be installed with:
	`npm install hbs`

*Node.js, Express and hbs Setup*
```JavaScript
import path from 'path';
import express from 'express';
import hbs from 'hbs';
import { dirname } from 'path';
import { fileURLToPath } from 'url';

const app = express();

const __filename = fileURLToPath(import.meta.url);
const __dirname = dirname(__filename);

// Define paths for Express config
const publicDirPath = express.static(path.join(__dirname, '../public'))
const viewsPath = path.join(__dirname, '../templates/views');

// Set up handlebars engine and views location
app.set('view engine', 'hbs');
app.set('views', viewsPath);

// Set up static dir to serve
app.use(publicDirPath);
```

Setup Checklist
- Initialize Express (typically in a constant named app)
- Set up a public path for static resources. Set with `app.use(<path to public directory>)`
	- Static HTML
	- CSS
	- client-side JavaScript
	- images
- Set the template engine with `app.set(‘view engine’, ’hbs’);`
- Set the path to the template files with `app.set('views', \<path to views>);`
