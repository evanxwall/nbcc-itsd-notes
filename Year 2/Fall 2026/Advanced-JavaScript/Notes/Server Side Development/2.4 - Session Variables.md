### Introduction
- HTTP is a **stateless protocol**. Once a browser makes a request, it drops the connection to the server. To maintain state, a web application must use **session tracking**. 
- Node.js, Express, and the Express session module uses a cookie to store a session ID in each browser. Then, the browser passes the cookie to the server with each request.
- Cookies must be enables in the browser to support sessions. Users can enables and disable cookies. 
- In the modern web, it can be difficult for users to leverage web site/application features without cookies enabled.
- To store the data for each session, the server creates a session object within the request object as a session property. 

### How to Get Session Attributes
- A session object is created when a browser makes the first request to a site. It is destroyed when the session ends. 
- A session ends when a specified amount of time elapses without another request or when the user exits the browser. 

Express Session Variables can be installed with
	`npm install express-session` - This is a separate package from our base express

#### Express Middleware Setup
```JavaScript
import session from 'express-sessions';

app.use(session({ // added as middleware
	secret: 'wmad', saveUninitialized: true, resave: true, cookie: {
		maxAge: 30 * 24 * 60 * 60 * 1000
	}
}));
```

- The `secret` property prevents session hijacking.
- `saveUninitalized` creates a new session if not yet presented.
- `resave` Always resaves the session even if not changed.
- `cookie` is optional to configure maxAge in seconds. 

#### Getting and Setting Sessions
```JavaScript
// Response Object

app.get('', (req, res) => {
	let counter = req.session.counter;
	/* 
		Get the Session Variable Value:
		    The session property of the request object
		    is the session, and the variable is available by
		    name using dot notation	
	*/
});
```

```JavaScript
// Request Object

app.get('', (req, res) => {
	req.session.counter = 5;
	/*
		Set session variable value:
		    The session property of the request object is
		    the session, and the variable is available by
		    name using dot notation and is assigned using 
		    the = sign. like any other variable or property
		    value.
	*/
});
```

*Complete Example from Slide 10*
```JavaScript
import express from 'express';
const app = express();
const port = process.env.PORT || 3000;

app.use(session({
	secret: 'wmad', saveUninitialized: true, resave: true, cookie: {
		maxAge: 30 * 24 * 60 * 60 * 1000
	}
}));

app.get('', (req, res) => {
	let counter = req.session.counter ?? 0;
	counter += 1;
	req.session.counter = counter;
	res.send({ counter });
});

app.listen(port, () => {
	console.log(`Express Listing on Port: ${port}`);
});
```
