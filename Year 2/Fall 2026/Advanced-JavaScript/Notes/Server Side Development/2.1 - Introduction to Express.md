### Node.js And Web Servers
Referring back to [[2.0 - Server-Side Development]]
- Node.js is Commonly used as a web server to serve web applications, JSON, REST APIs and more
- Using the Node.js core HTTP module, we can spawn a web server and serve a web application

There is problems with this approach...

#### Challenges of Server-Side In Node.js
- Low level management of non-essential business features
	- Setting response header codes
	- Parsing of routes for rendering particular resources (Web Pages)
	- Parsing request parameters
- Splitting focus of lower-level tasks and value-added application features

### Express Framework

#### What is Express.js?
- We can use Node.js to make web servers but they can be challenging
- Express is a web application **Framework** to assist and ease in the rapid development of web applications using Node.js
	- **Framework**: Collection of software libraries that provide fundamental structure to support application development.
- It eliminates complexity of low-level web server development and allows developers to focus on delivering features 
- Express is free and open-source software under the MIT License

#### Why use Express?
- Promotes rapid development
- Focus of developing on application value
- Eliminates low level application code for handling http communications
- Offers support for advanced templating for producing dynamic HTML 
	- Layouts
	- Templates
	- Partials

You can install express by opening you terminal within you project folder or through VSCode
	`npm install express`

*Example of Node.js using Express*
```JavaScript
const express = require('express');
const hbs = require('hbs');

const app = express();

app.set('view engine');

app.get('', (req, res) => {
	res.render('index', {
		title: 'home',
		renderedDate: new Date()
	});
});

app.get('/courses', (req, res) => {
	res.render('courses', {
		title: 'courses',
		renderedDate: new Date()
	});
});

app.get('/instructors', (req, res) => {
	res.render('instructors', {
		title: 'instructors',
		renderedDate: new Date()
	});
});

app.listen(3000, () => {
	console.log("Server is running on port 3000");
});
```
