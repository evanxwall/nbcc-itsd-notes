### HTTP
- HTTP(S) stands for Hypertext Transfer Protocol (Secure)
	- Hypertext: Text that is displayed on a computer device display
	- Transport: Movement from point A to point B
	- Protocol: Set of rules or official procedure
	- Secure:  To hold, or possess or obtain in a manner to avoid damage or harm

- HTTP has its own methods which we use to request data
	- GET 
	- POST
	- PUT
	- DELETE
	- PATCH
	- HEAD
	- TRACE
	- OPTIONS
	- CONNECT

GET, POST, PUT, and DELETE will be the ones we are focusing on.

#### HTTP GET
GET Requests (Commonly called from a browser in the address bar)
- Uses the URL and optional parameters
- Can be bookmarked
- Remain in browser history
- Can be cached
- Should not be used for sensitive data
- Have length restrictions
- Should only be used to get data

**URL Example:**
 https://nbcc.ca/programs-courses/program-details?baseCurriculumId=a3dc93ce-e29b-49e5-bf3c-d5374530e205

`https://nbcc.ca/programs-courses/program-details`            - Requested Resource
`baseCurriculumId=a3dc93ce-e29b-49e5-bf3c-d5374530e205`   - Request Parameters

- The Resource and Parameters are separated with a `?`

**HTTP GET Request with Express Route Parameters**
```JavaScript
import express from 'express'; 
const app = express(); 

// ----- Set A Single Parameter within the URL -----
app.get('', (req, res) => {
    res.send('Home page');
});
 
app.get('/course/:id', (req, res) => { // :id - A named route parameter
    res.send(`You sent course id: ${req.params.id} in your GET request as a path parameter`);                        // Access Named Routed 
}); 

app.listen(3000, (req, res) => {
    console.log('Express listening on port 3000'); 
});


// ----- Set Multiple Parameters within the URL -----
app.get('', (req, res ) => {
    res.send('Home page');
});

app.get('/course/:id/:instructor', (req, res ) => { // Sets :id and :instructor
    res.send(`You sent course id: ${req.params.id} and instructor: ${req.params.instructor} in your GET request as a path parameter`);
}); // Uses both to display the entered paramenter on the home page
 
app.listen(3000, (req, res) => {
    console.log('Express listening on port 3000'); 
});
```

#### HTTP POST
POST requests are commonly sent to the server via a web form
- Never cached
- Not stored in browser history
- Nothing to bookmark
- No restrictions on length
- Ship textual and binary( Images, Files) in a POST request
- Shipped in POST body and not visible in a URL is encrypted over HTTPS

**Http POST Request handling with Express using body parser middleware**
```HTML
<form method="POST" action="course">
<!-- Set the method to POST, set the action to the route we are targetting -->
    <label for="val1">Course:</label><br />
    <input type="text" name="courseNameToPost" />
    <!-- Name to textbox to get access to the value within the POST parameters -->
    <br /><br />    
    <button>Submit</button>
</form>
<div>
    {{course}}
</div>
```
