### PHP Syntax
A PHP script is executed on the server, and the plain HTML result is sent back to the browser and it can be placed anywhere in the document.

#### Basic PHP Syntax
A PHP script starts with `<?php` and ends with `?>`:
```PHP
<?php
	// PHP Code Here
?>
```

PHP files normally contain some HTML tags and some PHP scripting code
```PHP
<!DOCTYPE html>
<html>
<body>
	<h1>My First PHP Page!</h1>
	<?php
		// Single Line Comment
		#  Or use '#' instead
		/* 
			Block
			Comment
		*/
	
		$color = "red";
		$COLOR = "blue";
		// Variable ARE case sensitive, these are two different variables
		
		echo 'Hello World!';
		// All PHP statements end with a semi-colon ;
		
		ECHO 'Hello World!';
		// PHP keywords, classes, functions, and user-defined functions
		// ARE NOT case sensitive. Both echo statements are legal.
	?>
</body>
</html>
```

#### PHP Variables
Like any other language, variables are containers for storing information. variables can have short or descriptive names. `$x, $y, $myName, $myInt, etc..`

Rules for PHP Variables:
- Variables must start with `$` followed by the name of the variable
- Variable name must start with a letter or an underscore 
- Variable names cannot start with a number
- Variable names can only contain alpha-numeric characters and underscores (A-z, 0-9, and _ )
- Variable names are case-sensitive (`$age` and `$AGE` are two different variables)

```PHP
<!DOCTYPE html>
<html>
<body>
	<h1>PHP Variables</h1>
	<?php
		// ----- Two Simple Variables -----
		$x = 5;      // This is an Int
		$y = "Chad"; // Quotes for text variables, also a string
		
		$vari1 = $vari2 = $vari3 = "Fruit";
		// You can also assign multiple variables the same value
		
		// PHP has no command for declaring a variable. 
		// It is created the moment you assign a value to it.
		
		// ----- Showing Output -----
		// Echo is often used to output data to the screen
		$txt = "Warframe";
		echo = "Yeah, $txt is pretty cool";
		
		echo = "Yeah, " . $txt . " is pretty cool";
		// This produces the same output as our first echo
		
		// ----- Simple Math with Variables -----
		$num1 = 5;
		$num2 = 2;
		$num3 = 25;
		
		echo $num1 + $num2 // Output: 7
		echo $num1 - $num2 // Output: 3
		echo $num1 * $num2 // Output: 10
		echo $num3 / $num1 // Output: 5
	?>
</body>
</html>
```

PHP is a **loosely typed language.** We don't have to declare which data type a variable is, just like JavaScript. PHP automatically associates a data type to the variable, depending on its value. Since the data types are not set in a strict sense, you can do things like adding a string to an integer without causing an error.
	Declarations were added in PHP 7. This gives you the option to specify what data type is expected when declaring a function. You can also enable the strict requirement.

Supported Variables Types
- **string** (text values)
- **int** (whole numbers)
- **float** (decimal numbers)
- **bool** (true or false)
- **array** (multiple values)
- **object** (stores data as objects)
- **null** (empty variable)
- **resource** (references external resources)
- **mixed** (any value)

**Get a Data type using `var_dump()`**
```PHP
<!DOCTYPE html>
<html>
<body>
	<h1>PHP Variables</h1>
	<?php
		var_dump(5);
		var_dump("John");
		var_dump(3.14);
		var_dump(true);
		var_dump([2, 3, 56]);
		var_dump(NULL);
		
		/* Output
			int(5)
			string(4) "John"
			float(3.14)
			bool(true)
			array(3) {
			  [0]=>
			  int(2)
			  [1]=>
			  int(3)
			  [2]=>
			  int(56)
			}
			NULL
		*/
	?>
</body>
</html>
```

#### PHP Variable Scope
- PHP variables can be declared anywhere in PHP code
- The scope of a variable is the part of the script where the variable can be referenced / used. 
- Three different PHP variable scopes:
	- `global`
	- `local`
	- `static`


**Global Scope**
- A variable declared **outside** a function has a Global Scope and can only be accessed outside a function
```PHP
$x = 5; // Global Scope

function myTest() {
	// Using x within this function will not work
	echo "Variable x inside this function is: $x";
	// This won't return any output
}

myTest();
echo "Variable x outside this function is: $x";
// This will return and output of 5
```

**Local Scope**
- A variable declared within a function has Local Scope. It can only be accessed within that function
- Local variables are created when the function is called and are destroyed when the function finishes executing.
```PHP
function myTest() {
  $x = 5; // local scope
  echo "Variable x inside function is: $x";
  // Output will be 5
}

myTest();
echo "Variable x outside function is: $x"
// using x outside the function will not work
```

**Static Scope**
- We can use the static keyword to keep a local variable around even after a function has finished executing. 
- Then, each time the function is called, that variable will have the value from the last time the function was called.
```PHP
function myTest() {
  static $x = 0; // static scope
  echo $x;       // Output
  $x++;          // Increment
}

myTest(); // Output 0
myTest(); // Output 1
myTest(); // Output 2
```

**Global Keyword**
- We can use the `global` keyword to access variables from within a function.
- Use the global keyword before the variables (Inside the function) to use it.
```PHP
$x = 5;
$y = 10;

function myTest() {
  global $x, $y; // Access the Global Variables
  $y = $x + $y;  // Do some work with them
}

myTest();
echo $y; // outputs 15
```


**$GLOBAL Superglobal**
- PHP stores all global variables in an array called `$GLOBALS[index]`
- The index holds the name of the variables
- It can be accessed within functions as well. 
```php
$x = 5;
$y = 10;

function myTest() {
  $GLOBALS['y'] = $GLOBALS['x'] + $GLOBALS['y'];
  // Access the Global Variables we created at the top.
  // This also updates y
}

myTest();
echo $y; // outputs 15
```
