### What is PHP?
- PHP is an acronym for "PHP: Hypertext Preprocessor"
- PHP is a widely-used, open source server-side scripting language
- PHP scripts are executed on the server
- It is free to download and use

PHP is a popular language that is able to build and support large blog systems, run large social networks, and it's a beginner-friendly server-side scripting language.

#### Why PHP?
- It runs on all major platforms (Windows, Linux, Unix, Mac OS., etc..)
- It's compatible with all leading web servers (Nginx, Apache, Cloudflare, Microsoft IIS, etc..)
- It supports a wide range of databases (MySQL, PostgreSQL, MSSQL, db2, Oracle Database, MongoDB, etc..)
- It's free - [Download PHP](https://www.php.net/)
- Easy to learn

#### What is a PHP File?
- has the `.php` extension
- PHP files can contain text, HTML, CSS, JavaScript and PHP code
- Code is executed on the server and the result is returned to the browser at HTML

#### What Can PHP do?
- Generate dynamic page content
- Create, open, read, write, delete, and close files on the server
- Collect form data
- Send and receive cookies
- Add, delete, modify data within your database
- Used to control user-access
- Can encrypt data

With PHP you are not limited to output HTML. You can output images or PDF files. You can also output any text, such as XHTML and XML.
