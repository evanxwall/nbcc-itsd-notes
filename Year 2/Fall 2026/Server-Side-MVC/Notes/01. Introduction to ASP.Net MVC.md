### What is MVC?

- ASP.Net MVC is a Web Application Framework that gives you a powerful MVC architecture-based way to build dynamic web applications.
- It enables a clean separation of concerns (Separating the GUI from the logic) and gives you full control over markup.
- It is part of ASP.Net
- Alternative to ASP.Net Web Forms. 
- It's faster than its alternatives.

#### MVC (Model View Controller)

- Model
	- Data Structure
	- Business Logic

- View
	- Presentation Logic
	- Reads Data from Model

- Controller
	- Defines Execution Flow
	- Executions starts from the controller
	- Fills Data into Model object
	- Pass Model object to view

#### Advantages of MVC
- Supports clean separation of concerns
- Supports unit testing
- Supports dependency injection
- Supports faster performance than Web Forms
- No Page Life Cycle, Controls, Postback, ViewState

### Controllers
- Controller(s) is a class that defines execution flow in a MVC application
- Controller gets request from browser, call the model, call the view

#### Controller Class
- It is a class
- It can be a public class
- A controller's properties and methods should be inherited from the *System.Web.Mvc.Controller* class
- Should be named proper. Ex: *HomeController*
- Controllers methods are called as *ActionMethods* each action represents a specific operation.

*Example of a Controller Class*
```C#
public class classnameController : System.Web.Mvc.Controller
{
	// It's a class, thats all thats here.
}
```

*Example Of Action Methods within a Controller*
```C#
public class HomeController : Controller
{       
	public ActionResult Index()       
	{          
		return View();       
	}         
	
	public ActionResult Products()       
	{           
		return View("OurCompanyProducts");      
	}
}
```
#### ActionResult Class
- The ActionResult class represents the result of an ActionMethod
- It an abstract class that has several child classes.
- You can return an object of any of the child classes
- ASP.Net MVC recommends to specify action methods return type as *ActionResult*

![[mvcActionResult.png| Diagram from slide 13]]

#### Types of ActionResults
- **ContentResult**: Represents any content with specific content-type. 
- **ViewResult**: Represents the result of a view.
- **FileResult**: Represents content of a file.
- **JsonResult**: Represents JSON object / JSON array
- **RedirectResult**: Represents redirection to other website (HTTP 302):
- **RedirectToRouteResult**: Represents redirection to a specific action method (HTTP 302). 
- **PartialViewResult**: Represents the result of partial view

#### Folder Structure of MVC App
- \App_Start:  Contains the files that needs to be executed on the first request.
- \App_Data:  Contains SQL Server LocalDb Database Files.
- \Controllers:  Contains all controllers.
- \Models:  Contains all models.
- \Views:  Contains all views.
- \Views\web.config:  Contains configuration settings for all views.
- \Global.asax:  Contains application level and session level events.
- \packages.config:  Contains the list of NuGet packages currently installed in the project.
- \Web.config:  Contains web application configuration settings, that needs to be initialized on each request.
### View
- It's a .cshtml file that contains the presentation logic of the application
- The Controller passes the model object to the view and the view reads the dad from the same model object. 
- Typically, every action method contains a view. 
- ASP.Net MVC supports two type of view engines.
	- ASPX View Engine (Ass)
	- Razor View Engine (Good)

![[mvcContollerBad.png| Diagram from slide 16]]

#### Razor View Engine
- Razor is the latest and advanced view engine. Supported in MVC 3, 4, 5
- File extension is .cshtml (or .vbhtml)
- Syntax is very clear, clean and expressive
- You can write the HTML tags in the code blocks.

Example of writing C# within an .cshtml file with Razor
```HTML
<div>@c#.netcode</div>
```

Example of writing C# code block within an .cshtml with Razor
```HTML
<div>
@{
	c#.netcode line 1;
	c#.netcode line 2;
	c#.netcode line 3;
	etc...
}
</div>
```

Example of writing C# if statement within an .cshtml with Razor
```HTML
<div>
@if (condition)
{
	html content here
}
else
{
	html content here
}
```

Example of writing C# for loop within an .cshtml with Razor
```HTML
<div>
@for (initialization; condtion; decrementaion)
{
	html content here 
}
</div>
```

Example of writing C# foreach within an .cshtml with Razor
```HTML
<div>
@foreach (var variable in collection)
{
	html content here
}
</div>
```

Example of writing C# comments within an .cshtml with Razor
```HTML
<div>
@*
	comment line 1
	comment line 2
	etc...
*@
</div>
```

- Pretty much just us the @ operator to access C# code for your project.
