### What is HTTP?
- Hyper-Text Transfer Protocol
- Other Protocols: FTP, SMTP
- HTTP is an application-protocol that defines set of rules to send request from browser to server and send response from server to browser. 
- Initially developed by Tim Berners Lee, standardized by IETF (Internet Engineering Task Force) and W3C

#### HTTP Methods - Quiz Question

| :----------------------------------------------------------------------------------------------: | :------------------------------------------------------------------: |

#### HTTP Request Readers
- **Accept:**
	 Informs the server what type of content the client is expecting. Ex: text / HTML

- **Accept-Language:**
	 Informs the server which language content the client is expecting. Ex: en-US

- **Content-Type:**
	 MIME type of request body (useful for POST and PUT) Ex: 
		text/x-www-form-urlencoded 
		[or] 
		multipart/form-dataMyVariableOne=ValueOne&MyVariableTwo=ValueTwo

- **Content-Length:**
	 Length of request body (useful for POST and PUT)
	 Ex: 100

- **Date:**
	 Date and time of request. 
	 Ex: Fri, 18 Sept 2026 11:01:30 AST

- **Host:**
	 Server domain name. Ex: www.website.com

- **User-Agent:**
	 Browser Details. Ex: Mozilla / 5.0 Firefox / 12.0

- **Cookie:**
	 Contains cookies to send to the server. Ex: x=100

### HTTP Status Codes
- 100: Continue
- 200: OK
- 201: Created
- 302: Redirection
- 304: Not Modified
- 400: Bad Request
- 401: Unauthorized
- 404: Not Found
- 500: Internal Server Error

### Request Properties
- **Request.Url:**
	Represents current URL. Ex: http://localhost:1020/home/index

- **Request.PhysicalApplicationPath:**
	Represents current folder path. Ex: c:\mvc\MyFirstApp

- **Request.Path:**
	Represents current virtual path. Ex: /home/index

- **Request.Browser.Type:**
	Represents current browser name. Ex: Chrome56

- **Request.QueryString:**
	Represents current query string. Ex: Param1=Value1&Param2=Value2

- **Request.Headers:**
	Represents request headers (Key Value Pairs)

-  **Request.HttpMethod:**
	Represents http method of the request (GET / POST )


### Response Properties
- **Response.Write():**
	 Sends given content to the browser

- **Response.ContentType:**
	 Represents type of response content. Ex: text / HTML

- **Response.Headers:**
	 Represents response headers that can be sent from the server to the browser

- **Response.StatusCode:**
	 Represents status of request. Ex: 200, 302, etc...
