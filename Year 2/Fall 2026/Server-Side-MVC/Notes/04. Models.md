### What is a Model?
- Model is a class that defines structure of the data that you want to display / store
- Also Contains Business Logic
- Models will be called by a controller and the view

#### Different Types of Models
- View Model:
	 Represents the structure of the data that you want to display to the user

- Domain Model:
	 Represents the structure of data that you want to store in the database table

- Service Model:
	 Represents business logic (Code that needs to be executed before inserting / updating, etc.)

### Strongly Typed Views
- A View that is associated to a specific model class is called as a "Strongly Typed View"
- Strongly typed views have to specify the model class name with @model directive at the top of the view

```C#
@model List<ModelDemo.Models.Product>
// This is the model Directive at the top of the view

<!-- This also goes at the very top, binding the list to the view -->
@{
    ViewBag.Title = "Index";
}

<h2>Index</h2>
```

- Strongly Typed views can receive model objects from the controller 
- To receive model collections from the controller: @model List\<modelClassNameHere>

### Model Binding
- Process of "receiving values from different sources of the request and passing them as arguments to action methods"
- Assigns values to different parameters of the action method automatically

#### Model Binding with Complex Types
- Model Binding can work with Complex Types
- Model Binding can automatically convert form field data or query string values to the properties of a complex type parameter of an action method.
- Default values are null or zero 0.
