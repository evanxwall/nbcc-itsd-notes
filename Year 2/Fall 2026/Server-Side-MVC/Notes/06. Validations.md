### What Are Validations?
- Validations never go away, no matter than language.
- They are defined using data annotations
- Provided by: `System.ComponentModel.DataAnntations` namespace 

*Basic Example*
```C#
public class Employee 
{
	[Required]
	public int EmpID { get; set; }
	// Just meams this field is required for an object to be created
}
```

#### Different Annotations
- `[Required]` -   Field is mandatory
- `[MaxLength]` -   Maximum number of characters
- `[MinLength]` -   Minimum number of characters
- `[Range]` -   Value should be within the min and max
- `[Compare]` -   Two fields must be the same
- `[RegularExpression]` - Pattern of Value
- `[EmailAddress]` - Email Address only accepted

*From the demo we did Wednesday October 21st in the Product.cs Model*
```C#
using System;
using System.Collections.Generic;
using System.Linq;
using System.Web;
using System.ComponentModel; // Add This 
using System.ComponentModel.DataAnnotations; // and Add this to use the annotations

namespace ModelExample.Models
{
    public class Product
    {
        [Required(ErrorMessage = "No ProductId was given.")] 
        // Right above the property, put whatever annotation you want
        public int ProductId { get; set; }

        [Required] 
        // Now the user needs to fill out both ProductId and ProductName
        [MinLength(5)]  
        // You can also stack annotations
        public string ProductName { get; set; }

        [Range(0, 9999)] // Sets Range
        [Required] 
        public double Rate { get; set; }
    }
}
```

### Server Side Validation
- `ModelState.IsValid` checks whether the model object satisfied all the validations rules.
- Check ModelState in the Controller

### Client Side Validation
- jQuery - Performs DOM manipulations
- jQuery.Validation - Defines validation rules
- Microsoft.jQuery.Unobtrusive.Validation - Show / hide error messages

#### HTML Helpers for Client Side Validation
- `ValidationMessageFor` - Displays Error Message
- `ValidationSummary` - Displays Validation summary

*From the demo we did Wednesday October 21st*
```html
<!-- This is a HTML code block cuz it looked better but this is .cshtml code -->
@model ModelExample.Models.Product
@{
    ViewBag.Title = "Create";
}

<h2>Create Product</h2>
<form action="/Products/Create" method="post">
    <div class="form-group">
        @Html.LabelFor(m => m.ProductId)
        @Html.TextBoxFor(m => m.ProductId, new { @class = "form-control" })
        @Html.ValidationMessageFor(m => m.ProductId, "", new { @class = "text-danger" }) <!-- Example of the Validation Message -->
    </div>
    <div class="form-group">
        <label>Product Name</label>
        <input type="text" class="form-control" id="txtProductName" placeholder="Product Name" name="ProductName">
    </div>
    <div class="form-group">
        <label>Rate</label>
        <input type="text" class="form-control" id="txtRate" placeholder="Rate" name="Rate">
    </div>
    <button class="btn btn-success">Submit</button>
</form>
@Html.ValidationSummary()
<!-- Displays any validation issues. Add this to the end, it's all you need, just make it look good with CSS -->
```
