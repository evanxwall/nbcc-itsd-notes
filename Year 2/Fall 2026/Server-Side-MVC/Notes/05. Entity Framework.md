### What is Entity Framework?
- Entity Framework (EF) is a database technology, which is build based on ADO.NET, that supports ORM (Object - Relational Mapping) pattern
- It bridges between "Object Oriented Programming" and "Relational Databases", using Model Classes

#### Entity Framework - Features
- Modeling
- Querying (LINQ or SQL)
- Change Tracking (Property Values)
- Saving (Insert, Update, Delete)
- Concurrency (Optimistic)
- Transactions
- Caching (When querying)
