### Overview

- HTTP is a **stateless protocol**. Once a browser makes a request, it drops the connection to the server.
- To maintain a connection, a web application must use **session tracking** 
- The servlet API uses a **cookie** to store session ID by default. 
- The browser passes the cookie to the server with each request.
- You can use **URL encoding** to provide session tracking if cookies are disabled. 
- storing Data for each session is stored in a **session object**

### How to Get and Set Session Attributes
- A Session object is created when a browser makes the first request to a site. It is destroyed when the session ends.
- A session ends when a specified amount of time elapses without another request or when the user exits the browser
- The session object is a built-in JSP object. Meaning you don't need to create a session object working with JSPs

#### Session and Request Object

Request Object Method:
- .getSession() - Returns the HttpSession object associated with this request. If the request is not associated with a session, this methods creates a new HttpSession object and returns its. 

Session Object Methods:
- .setAttributes(String name, Object o) - Store any object in the session as an attribute and specifies a name for the attribute.
- .getAttribute(String name) - Returns the value of the specified attribute as an object type. If no attribute exists for the specified name, this method returns a null value.
- .removeAttribute(String name) - Removes the specified attribute from this session. 
- .getAttributeNames() - Returns a java.util.Enumeration object that contains the names of all attributes in the HttpSession Object. 
  - .getId() - Returns a string for the unique Java session identifier that the servlet engine generates for each session.
  - .isNew() - Returns a true value if the client does not yet know about the session or if the client chooses not to join the session.
  - .setMaxInactiveInterval(int seconds) - By default, the maximum inactive interval for the session is set to 1800 seconds = 30 mins. To increase or decrease this interval, supply a positive integer value. To make the session never end, set the value to -1 or any negative integer.
  - .invalidate() - Invalidates the session and unbinds any objects that are bound to it.
