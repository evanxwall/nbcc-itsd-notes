# NBCC Class Resources Repo

Simple repo for the NBCC IT:SD classes to easily access different class resources. Also to act kind of like an archive.\
You will be able to find:

* Notes
* Slides
* Demos
* Examples
* Exercises
* External Resources

As of right now, this is ran and organized by one student but things will be added ASAP.\

**NOTE: Exercises and Examples ARE NOT graded.**\  
They are examples from the textbook or external resources. They will be primarily code snippets showing a simple example and then a small example showing them being used in some sort of app.
